# AUTOVANTA — Phase 1

A premium automotive exploration prototype.

## Run locally

Requirements:
- Node.js 18+ (Node 20+ recommended)
- VS Code

```powershell
cd "D:\YOUR_PATH\AUTOVANTA"
npm install
npm run dev
```

Open the local URL shown by Vite, usually:
http://localhost:5173

## Current Phase 1 features

- Cinematic homepage
- Curated vehicle collection
- Vehicle switching
- Search modal
- Signature Build DNA interaction
- Engineering layer explorer
- Lab concept section
- Comparison table
- Responsive desktop/mobile UI
- GSAP entrance motion

## Important

Vehicle data in this prototype is intentionally limited and marked as demo/curated data. Before production launch, connect every specification to verified sources and preserve model-year/market context.
